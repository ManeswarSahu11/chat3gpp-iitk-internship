Title Path: Introductory information > Introduction
Content: The confidentiality algorithm GEA5 is a stream cipher that is used to encrypt/decrypt blocks of data under a confidentiality key KC128. The block of data may be between 1 and 65536 octets long. The algorithm uses SNOW 3G as a keystream generator. The integrity algorithm GIA5 computes a 32-bit MAC (Message Authentication Code) of a given input message using an integrity key KI128. The approach adopted uses SNOW 3G.

Title Path: Introductory information > List of variables
Content: [CONSTANT-F]a 32-bit parameter which is constant for any given FRAMETYPE input. the 1-bit input to both the GEA5 and GIA5 functions indicating the direction of transmission (uplink or downlink). an 8-bit input to the GEA5 and GIA5 functions indicating the type of frame to be protected. the 32-bit time variant input to the GEA5 function. [INPUT-I]the 32-bit time variant input to the GIA5 function. the 128-bit confidentiality key. the 128-bit integrity key. [KS ]the ith bit of keystream produced by the keystream generator. the number of 32-bit words of SNOW 3G keystream that are generated by GEA5 (equal to M / 4). a 64 bit parameter defined within GIA5 which specifies the number of bits of message to be MAC'd (equal to 8 times M). the input to the GEA5 function which specifies the number of octets of output required (1-65536); also the input to the GIA5 function which specifies the number of octets of message to be MAC'd (1-65536). the 32-bit message authentication code (MAC) produced by the integrity function GIA5. the input bitstream of LENGTH bits that is to be processed by the GIA5 function. the output octets from the GEA5 function. [S1, S2, ]a sequence of 64-bit words derived from MESSAGE and LENGTH which is used within GIA5 to construct the MAC. [z1, z2, ]the 32-bit words forming the keystream sequence of SNOW 3G. The word produced first is z1, the next word z2 and so on.
