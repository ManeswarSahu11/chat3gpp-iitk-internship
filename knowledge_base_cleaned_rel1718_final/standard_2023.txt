Title Path: Scope
Content: The present document defines the Network Resource Model (NRM) for the SuM IRP which can be communicated between an IRPAgent and IRPManagers for subscription management purposes, including in the context of converged networks .

Title Path: Model > Class definitions > CSSubscribedService > Definition
Content: This class represents subscription to a CS service (see TS 23.008 ) for a subscriber. The entire set of CS subscribed services owned by a subscriber constitutes the subscriber's Subscribed Services Profile for CS services. This class contains the agreed (between the Subscriber and the Service Provider) parameter settings for a CS service that a Subscriber subscribes to.
Title Path: Model > Class definitions > GPRSSubscribedService > Definition
Content: This class represents subscription to a GPRS service (see TS 23.008 ) for a subscriber. The entire set of GPRS subscribed services owned by a subscriber constitutes the subscriber's Subscribed Services Profile for GPRS services.
Title Path: Model > Class definitions > IMSSubscribedService > Definition
Content: This class represents subscription to an IMS (see TS 23.008 ) service for a subscriber. The entire set of IMS subscribed services owned by a subscriber constitutes the subscriber's Subscribed Services profile for IMS services. This class contains the agreed (between the Subscriber and the Service Provider) parameter settings for an IMS service that a Subscriber subscribes to.
Title Path: Model > Class definitions > SuMSubscriberProfile > Definition

Title Path: Model > Class definitions > SubscriptionFunction > Definition
Content: This class represents subscription functionality. All managed elements related to the subscription of services have this functionality. This class inherits from ManagedFunction (defined in 32.622 ). This class contains the reference to its aggregated Users. This class contains the reference to its aggregated Subscriber Profiles.

Title Path: Model > Class definitions > IMSPublicIdentification > Definition

Title Path: Model > Class definitions > MobileUserData > Definition
Content: This class represents user data of a mobile User Equipment. This class contains the valid parameters that define the user data of the mobile User Equipment from subscription point of view.
Title Path: Model > Class definitions > SuMServiceParameter > Definition
Content: This class represents a structured Service Parameter defined for a service and is an abstract class provided for sub-classing only. This class shall be used as a base when having the requirement to provision common shared data referred to by specific SuMSubscribedService or SuMServiceProfile instances.
Title Path: Model > Class definitions > SuMIdentity > Definition
Content: This class represents a user related identity, regardless of any type service to be provisioned and is an abstract class provided for sub-classing only. This class allows an identity to be used for multiple services.
Title Path: Model > Class definitions > ServerCapabilities > Definition
Content: This class is used to provision common shared ServerCapabilities data referred by specific SuMSubscribedService or SuMServiceProfile instances. This class contains information to assist the I-CSCF in the selection of an S-CSCF for an IMS subscriber or a PSI user.
