Title Path: Scope
Content: The present document specifies the usage of the Unified Data Repository services for subscription data. It provides the resource definition and data model for subscription data used over the Nudr Service Based Interface. The protocol definition for Nudr Service Based Interface which is specific to subscription data is also specified in the present document. The stage 3 protocol definition for Nudr Service Based Interface which is common for subscription data, policy data, structure data and application data for exposure is specified in 3GPP TS 29.504 .
