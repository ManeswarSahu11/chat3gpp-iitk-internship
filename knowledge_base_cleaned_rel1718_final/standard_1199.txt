Title Path: Scope
Content: The present document defines the management object (MO) for Basic Communication Part (BCP) of IMS Multimedia Telephony (MMTEL) communication service. The MO for BCP of MMTEL communication service is compatible with OMA device management protocol specifications, version 1.2 and upwards, and is defined using the OMA DM device description framework as described in the enabler release definition OMA-ERELD_DM-V1_2 . The MO for BCP of MMTEL communication service consists of relevant configuration parameter that can be managed for a UE supporting the timer RequestTimeout specified in 3GPP TS 24.173 .

Title Path: MO for BCP of MMTEL communication service
Content: The MO for BCP of MMTEL communication service is used to manage settings of the UE, which supports a RequestTimeout timer. The timer RequestTimeout is configurable as specified in 3GPP TS 24.173 . The MO identifier is: urn:oma:mo:ext-3gpp-bcp:1.0. Protocol compatibility: This MO is compatible with OMA DM 1.2.
Title Path: MO configuration parameters > General
Content: This clause describes the configuration parameters for the MO for BCP of MMTEL communication service.
Title Path: MO configuration parameters > Node: / X
Content: This interior node acts as a placeholder for one or more accounts for a fixed node. Occurrence: OneOrMore Format: node Access Types: Get, Replace Values: N/A The interior node is mandatory for a UE supporting the UE role specified in 3GPP TS 24.173 . NOTE: One node is normally used. More nodes are only used in case the terminal supports multiple UICCs. Child nodes of this interior node which are not defined in this version of the present document are ignored.
Title Path: MO configuration parameters > / X /Name
Content: This leaf is a name for the settings for BCP of MMTEL communication service. Occurrence: ZeroOrOne Format: chr Access Types: Get, Replace Values: User displayable name
Title Path: MO configuration parameters > / X /Timer_RequestTimeout
Content: The Timer_RequestTimeout leaf defines the time between sending of an initial INVITE request and receipt of any SIP response. Occurrence: One Format: int Access Types: Get, Replace Values: The time for INVITE request timeout The Timer_RequestTimeout leaf is the time between sending from the UE the initial INVITE request and the receptions of any SIP responce. The timer value shall be given in seconds. The configurable value is between 5 and 15 seconds referring to 3GPP TS 24.173 . The Timer_RequestTimeout is a 16 bits unsigned integer.
