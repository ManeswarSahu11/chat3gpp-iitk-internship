Title Path: Scope
Content: The present document defines the unstructured supplementary service data (USSD) using IP Multimedia (IM) Core Network (CN) subsystem (IMS) management object (MO). The MO is compatible with OMA device management protocol specifications, version 1.2 and upwards, and is defined using the OMA DM device description framework as described in the enabler release definition OMA-ERELD_DM-V1_2 . The USSD using IMS (USSI) MO consists of relevant configuration parameters that can be managed for the UE's USSI capabilities specified in 3GPP TS 24.390 .

Title Path: USSI MO
Content: The USSI MO is used to manage settings of the UE for USSI. The USSI MO covers configuration parameters for a UE that supports the USSI capabilities specified in 3GPP TS 24.390 . The MO identifier is: urn:oma:mo:ext-3gpp-ussi:1.0. Protocol compatibility: This MO is compatible with OMA DM 1.2.
Title Path: MO configuration parameters > General
Content: This clause describes the configuration parameters for the USSI MO.
Title Path: MO configuration parameters > Node: / X
Content: This interior node acts as a placeholder for one or more accounts for a fixed node. Occurrence: OneOrMore Format: node Access Types: Get Values: N/A The interior node is mandatory if the UE supports USSI capabilities specified in 3GPP TS 24.390 . Support for a UE is defined by the UE role as specified in 3GPP TS 24.390 . NOTE: One node is normally used. More nodes are only used in case the terminal supports multiple UICCs.
Title Path: MO configuration parameters > / X /Name
Content: The Name leaf is a name for the USSI settings. Occurrence: ZeroOrOne Format: chr Access Types: Get Values: User displayable name
Title Path: MO configuration parameters > / X /USSD_using_CS_domain_only
Content: The USSD_using_CS_domain_only leaf indicates HPLMN operator preference for invocation of originating USSD requests using the mechanism specified in 3GPP TS 24.090 . This equates to "USSD requests are to be invoked via the CS domain" as described in 3GPP TS 23.221 . NOTE: In absence of this configuration parameter, originating USSD request are invoked in domain used for originating voice sessions as described in 3GPP TS 23.221 .
