Title Path: Scope
Content: The present document specifies UE pre-configuration for multicast/broadcast services (MBS) in order to receive the data of multicast communication services and broadcast communication services as specified in 3GPP TS 23.247 . The present document defines a management object (MO) that can be used to configure the UE with parameters related to reception of data of multicast communication services and broadcast communication services. The MO is compatible with the OMA Device Management (DM) protocol specifications, version 1.2 and upwards, and is defined using the OMA DM device description framework (DDF) as described in the Enabler Release Definition OMA-ERELD-DM-V1_2 . The MO consists of nodes and leaves conveying UE pre-configuration parameters used for multicast communication service and broadcast communication service selection and data reception.

Title Path: General description
Content: A UE can support multicast and broadcast service (MBS) that is a point-to-multipoint service in which data is transmitted from a single source entity to multiple recipients either to all users in a broadcast service area (MBS broadcast communication), or to users in a multicast group (MBS multicast communication) as defined in 3GPP TS 23.247 . The UE may support pre-configuration of information for services using MBS. If the UE is pre-configured with information related to services using MBS, the UE can discover and receive data for services by using the provisioned configuration. The UE pre-configuration contains a list of PLMNs in which for each PLMN, the following information is configured: [ a) ] PLMN ID of the PLMN for which the configuration applies; RAN information based on NR-ARFCN on which the broadcast communication service is available; list of TMGI, on which the broadcast communication service is available, each associated with user service description (USD) information (see 3GPP TS 26.517 ) for the MBS broadcast service. If TMGI and USD information for the MBS user service is configured for the PLMN selected for broadcast communication service, the UE uses the information configured therein to acquire the broadcast communication service; list of TMGI, on which the service announcement for broadcast communication service is available along with the associated USD information (see 3GPP TS 26.517 ) for the MBS user service announcement service. If TMGI and USD information for MBS user service announcement is configured for a PLMN selected for broadcast communication service, the UE uses the information configured therein to acquire the service announcement for broadcast communication service; and default DNN and S-NSSAI pair for PDU sessions that can be used to join MBS multicast sessions (as specified in 3GPP TS 24.501 ) for which no other information is available.
Title Path: Multicast/Broadcast UE pre-configuration > General
Content: The UE pre-configuration MO is used to configure the UE with parameters related to MBS (see 3GPP TS 23.247 ). The MO identifier is: urn: oma:mo:ext-3gpp-UE-pre-config-MBS:1.0. Editor’s note: The MO identifier needs to be registered. The OMA DM access control list (ACL) property mechanism (see OMA-ERELD-DM-V1_2 ) may be used to grant or deny access rights to OMA DM servers in order to modify nodes and leaf objects of the UE pre-configuration MO.

Title Path: UE pre-configuration MO parameters > General
Content: This clause describes the nodes and leaves of the UE pre-configuration MO parameters.
Title Path: UE pre-configuration MO parameters > Node: X
Content: This interior node acts as a placeholder for zero or one accounts for a fixed node. Occurrence: ZeroOrOne Format: node Access Types: Get Values: N/A
Title Path: UE pre-configuration MO parameters > X /Name
Content: The Name leaf is a name for the UE pre-configuration MO settings. Occurrence: ZeroOrOne Format: chr Access Types: Get Values: User displayable name The User displayable name shall be represented by Unicode characters encoded as UTF-8 as specified in IETF RFC 3629 and formatted using normalization form KC (NFKC) as specified in Unicode Standard Annex \#15; Unicode Normalization Forms .
Title Path: UE pre-configuration MO parameters > X /PLMNList
Content: The PlmnList node acts as a placeholder for per-PLMN configuration. Occurrence: ZeroOrOne Format: node Access Types: Get, Replace Values: N/A
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /
Content: This interior node acts as a placeholder for UE pre-configuration parameters for one PLMN. Occurrence: OneOrMore Format: node Access Types: Get, Replace Values: N/A
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /PLMNId
Content: The PLMNId leaf indicates a PLMN identity of the PLMN for which the UE pre-configuration parameters applies. Occurrence: One Format: chr Access Types: Get, Replace Values: PLMN identity The format of the PLMN identity is specified in 3GPP TS 23.003 .
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /TMGIConfiguration
Content: The TMGIConfiguration node acts as a placeholder for the TMGI configuration in the PLMN identified by the PLMNId leaf. Occurrence: One Format: node Access Types: Get, Replace Values: N/A
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /TMGIConfiguration/TMGIListForSA
Content: The TMGIListForSA node acts as a placeholder for the TMGI list and the MBS service announcement information for broadcast or multicast communication services. Occurrence: ZeroOrOne Format: node Access Types: Get, Replace Values: N/A
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /TMGIConfiguration/TMGIListForSA/ X
Content: This node acts as a placeholder for one or more TMGI and the MBS service announcement information for broadcast or multicast communication service. Occurrence: OneOrMore Format: node Access Types: Get, Replace Values: N/A
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /TMGIConfiguration/TMGIListForSA/ X /TMGI
Content: The TMGI leaf indicates a TMGI for the MBS service announcement information for broadcast or multicast communication service. Occurrence: One Format: chr Access Types: Get, Replace Values: TMGI The format of the TMGI is specified in 3GPP TS 23.003 .
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /TMGIConfiguration/TMGIListForSA/ X /USD
Content: The USD leaf provides MBS service announcement information for MBS service announcement service for broadcast or multicast communication service. Occurrence: ZeroOrOne Format: chr Access Types: Get, Replace Values: USD The format of the USD is defined in 3GPP TS 26.517 . NOTE: 3GPP TS 26.346 specifies the session description and parameters based on SDP.
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /TMGIConfiguration/TMGIListForService
Content: The TMGIListForService node acts as a placeholder for the TMGI list and the MBS user service announcement information for the MBS service for broadcast communication services. Occurrence: ZeroOrOne Format: node Access Types: Get, Replace Values: N/A
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /TMGIConfiguration/TMGIListForService/ X
Content: This node acts as a placeholder for one or more TMGI and MBS user service announcement information for the MBS service for broadcast communication services. Occurrence: OneOrMore Format: node Access Types: Get, Replace Values: N/A
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /TMGIConfiguration/TMGIListForService/ X /TMGI
Content: The TMGI leaf indicates a TMGI for broadcast communication service. Occurrence: One Format: chr Access Types: Get, Replace Values: TMGI The format of the TMGI is specified in 3GPP TS 23.003 .
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /TMGIConfiguration/TMGIListForService/ X /USD
Content: The USD leaf provides the MBS user service announcement information for the MBS service corresponding to the broadcast communication service. Occurrence: ZeroOrOne Format: chr Access Types: Get, Replace Values: USD The format of the USD is defined in 3GPP TS 26.517 . NOTE: 3GPP TS 26.346 specifies the session description and parameters based on SDP.
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /RANInfo
Content: The RANInfo node acts as a placeholder for the RAN-specific information. Occurrence: ZeroOrOne Format: node Access Types: Get, Replace Values: N/A
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /RANInfo/ X
Content: This node acts as a placeholder for one or more NR ARFCN values of one or more MBS frequencies. Occurrence: OneOrMore Format: node Access Types: Get, Replace Values: N/A
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /RANInfo/ X /NRARFCN
Content: The NRARFCN leaf indicates the NR-ARFCN value of one MBS frequency. Occurrence: One Format: int Access Types: Get, Replace Values: NRARFCN The value of the NRARFCN is a 32-bit long unsigned integer. The format of the NR-ARFCN is specified in 3GPP TS 38.101-1 and 3GPP TS 38.101-2 .
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /PDUInfo
Content: The PDUInfo node acts as a placeholder for the PDU session-specific information. Occurrence: ZeroOrOne Format: node Access Types: Get, Replace Values: N/A
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /PDUInfo / X
Content: This node acts as a placeholder for one or more PDU session-specific information values. PDU session-specific information consists of DNN and S-NSSAI pair for a PDU session that can be used to join MBS multicast session(s). Occurrence: OneOrMore Format: node Access Types: Get, Replace Values: N/A
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /PDUInfo/ X /DNN
Content: The DNN leaf indicates the DNN value of one PDU session associated with an MBS session. Occurrence: One Format: chr Access Types: Get, Replace Values: DNN The format of the DNN is defined by 3GPP TS 23.003 in clause 9A. EXAMPLE: mycompany.mnc012.mcc340.gprs
Title Path: UE pre-configuration MO parameters > X /PLMNList/ X /PDUInfo / X /S-NSSAI
Content: The S-NSSAI leaf indicates the S-NSSAI value of one PDU session associated with an MBS session. Occurrence: One Format: int Access Types: Get, Replace Values: S-NSSAI The format of the S-NSSAI is defined by 3GPP TS 23.003 in clause 28.4.2
Title Path: UE pre-configuration MO parameters > X /Ext
Content: The Ext is an interior node for where the vendor specific information about the UE pre-configuration MO is being placed (vendor meaning application vendor, device vendor etc.). Usually the vendor extension is identified by vendor specific name under the ext node. The tree structure under the vendor identifier is not defined and can therefore include one or more non-standardized sub-trees. Occurrence: ZeroOrOne Format: node Access Types: Get Values: N/A
