Title Path: Scope
Content: The present document defines a Management Object (MO) that can be used to configure the UE with parameters related to Non-Access Stratum (NAS) functionality. The MO is compatible with the OMA Device Management (DM) protocol specifications, version 1.2 and upwards, and is defined using the OMA DM Device Description Framework (DDF) as described in the Enabler Release Definition OMA-ERELD-DM-V1_2 . The MO consists of relevant parameters for NAS related configuration of a UE.
Title Path: Definitions, symbols and abbreviations > Definitions
Content: For the purposes of the present document, the terms and definitions given in 3GPP TR 21.905 apply. Reserved: The value "reserved" is assigned to a code point to indicate that it is reserved for future use. The present document specifies no processing rules for handling of "reserved" value by the receiving entity. For the purposes of the present document, the following terms and definitions given in 3GPP TS 23.122 apply: EHPLMN HPLMN VPLMN For the purposes of the present document, the following terms and definitions given in 3GPP TS 23.501 apply: Stand-alone Non-Public Network For the purposes of the present document, the following terms and definitions given in 3GPP TS 24.301 apply: In NB-S1 mode For the purposes of the present document, the following terms and definitions given in 3GPP TS 23.221 apply: Restricted Local Operator Services For the purposes of the present document, the following terms and definitions given in 3GPP TS 24.501 apply: SNPN access operation mode NSSAI inclusion mode

Title Path: NAS configuration MO
Content: The NAS configuration MO is used to manage configuration parameters related to NAS functionality for a UE supporting provisioning of such information. The presence and format of the non-access stratum configuration file on the USIM is specified in 3GPP TS 31.102 . The MO identifier is: urn:oma:mo:ext-3gpp-nas-config:1.0. The OMA DM Access Control List (ACL) property mechanism (see OMA-ERELD-DM-V1_2 ) may be used to grant or deny access rights to OMA DM servers in order to modify nodes and leaf objects of the NAS configuration MO.
