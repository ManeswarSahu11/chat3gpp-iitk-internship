Title Path: Concepts and background
Content: The architectures of enhancement for non-3GPP access (i.e. WLAN) to 3GPP system are defined in 3GPP TS 23.402 . In TS 23.402, three kinds of architectures are defined, using S2a, S2b and S2c interface separately. The architectures of S2a and S2c don't introduce new network elements in 3GPP system, while the architecture S2b introduces a new network element to support the interworking: - evolved Packet Data Gateway (ePDG) (clause 4.3.4 of 3GPP TS 23.402 ). The above interworking related network element should be managed by the 3GPP OAM, and the corresponding NRM IRP needs to be defined. Based on the above characteristics, this specification defines the evolved 3GPP interworking WLAN NRM IRP requirements.
