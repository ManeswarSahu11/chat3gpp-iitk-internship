Title Path: Scope
Content: The present document specifies the Solution Set for the IRP whose semantics is specified in 3GPP TS 32.372 Security Service for IRP Information Service. This Solution Set specification is related to 3GPP TS 32.372 V14.0.X . Note that within the present document there are several alternate solutions. Specific choices will to be made to counter identified security threats, and to consider performance and cost criteria, i.e. an implementation is not expected to have to support every option for every deployment.
