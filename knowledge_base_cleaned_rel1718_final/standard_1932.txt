Title Path: Remote APDU Format > Response coding > (U)SIM specific behaviour for Response Packets (Using SMS-PP)
Content: If PoR is not requested, no data shall be returned by the (U)SIM’s RE/RA and the (U)SIM’s RE/RA shall indicate to the terminal to issue an RP-ACK. If PoR is requested, data shall be returned by the (U)SIM’s RE/RA. The (U)SIM’s RE/RA shall indicate to the terminal to issue an RP-ACK. The data returned by the (U)SIM is the complete Response Packet to be included in the User Data part of the SMS-DELIVER-REPORT. Because the (U)SIM is unable to indicate to the Terminal that the TP-UDHI bit is to be set, the Sending Entity receiving the Response Packet shall expect the UDH structure in any event. If a proof of Receipt is required by the sending entity, the Additional Response Data sent by the Remote Management Application shall be formatted according to ETSI TS 102 226 .

Title Path: Remote File Management (RFM) > SIM Remote File Management
Content: Command and Response formats are defined in ETSI TS 102 226 . Nevertheless, the list of commands defined in ETSI TS 102 226 for Remote File Management does not apply for SIM application. All the SIM Remote File Management commands are defined below. The standardised commands are listed in table 5.1. The commands are as defined in TS 51.011 , except that the SELECT command is extended from the one in TS 51.011 to include ``SELECT by path'' as defined in ISO/IEC 7816-4 . To retrieve the Response parameters/data of a case 4 command the GET RESPONSE command defined in TS 51.011 shall be issued (Class Byte is ‘A0’). The GET RESPONSE and any case 2 command (i.e. READ BINARY, READ RECORD) shall only occur once in a command string and, if present, shall be the last command in the string. The Response Data shall be placed in the Additional Response Data element of the Response Packet.

Title Path: Remote Applet Management > SIM File System Access Domain Parameter
Content: This parameter indicates the mechanism used to control the applet instance access to the SIM File System. It is a parameter of the INSTALL [for install] command described in ETSI TS 102 226 . This parameter shall be used only if the ``SIM File Access and Toolkit Application Specific Parameters'' TLV object (Tag ‘CA’) is present.

Title Path: Additional command for push
Content: The PUSH command behaviour shall comply with ETSI TS 102 226 . The specific behaviour of USIM Toolkit applications is stated below.
Title Path: Additional command for push > USIM specific behaviour for responses using SMS-PP
Content: The behaviour for responses shall comply with ETSI TS 102 226 . As the processing of the PUSH command may result in proactive commands being issued, the PUSH command result may be sent back in the additional response data of a response packet using SMS-SUBMIT.
Title Path: Additional command for push > USIM specific behaviour for response using HTTP
Content: The behaviour for responses shall comply with ETSI TS 102 226 As the processing of the PUSH command may result in proactive commands being issued, the PUSH command result may be sent back in the additional response data of a response packet using SMS-SUBMIT. The request for a TCP connection allows a remote entity to ask an application on the UICC to establish a TCP connection as defined in TS 102 483 . When Network Access Name, Text String (User Login), Text String (User Password) data object are present in PUSH command, the TCP connection shall be opened with these parameters. When Network Access Name, Text String (User Login), Text String (User Password) data object are not present in PUSH command, the TCP connection shall be opened respectively with Access Point Name Value, Login Value, Password Value stored in EF_NCP-IP (Network Connectivity Parameters for USIM IP connection), see 3GPP TS 31.102 .
