Title Path: 3GPP Mobile IPv6 Option > General
Content: The 3GPP Mobile IPv6 Option is a Mobile IPv6 Vendor-Specific Option as defined by IETF RFC 5094 using the Vendor-Id assigned to 3GPP. The 3GPP Mobile IPv6 Option is used to encode 3GPP Specific Information Elements within the protocols based on Mobile IPv6 (MIPv6) as defined by IETF RFC 6275 , such as the Dual Stack Mobile IPv6 (DSMIPv6) and Proxy Mobile IPv6 (PMIPv6) protocols respectively defined by IETF RFC 5555 and IETF RFC 5213 .
