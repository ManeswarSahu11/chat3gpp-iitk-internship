Title Path: Overview
Content: The Prose Anchor Function (PAnF) is the network entity in the 5G Core Network (5GC) supporting security procedure over Control Plane for the 5G ProSe UE-to-Network relay and 5G ProSe UE-to-UE Relay as specified in 3GPP TS 33.503 . Within the 5GC, the PAnF offers services to the AUSF and SMF via the Npanf service based interface. Figure 4-1 provides the reference model (in service based interface representation and in reference point representation), with focus on the PAnF: The PAnF supports the following functionalities: Storage and retrieval of ProSe context information of the 5G ProSe Remote UE and ProSe context information of the 5G ProSe End UE; Checking whether the 5G ProSe Remote UE is authorized to use the UE-to-Network Relay service and whether the End UE is authorized to use the UE-to-UE Relay service. Resolving the ProSe Remote User ID to SUPI.

Title Path: Services offered by the 5G PAnF > Npanf_ProseKey Service > Service Description
Content: The Npanf_ProseKey service enables an NF to request the PAnF to store the ProSe context information for a 5G ProSe Remote UE or to store the ProSe context information for a 5G ProSe End UE or to request CP-PRUK from the PAnF. The following are the key functionalities of this NF service. Store the Prose context information; Retrieve the Prose Key.
Title Path: Services offered by the 5G PAnF > Npanf_ProseKey Service > Service Operations > Introduction
Content: The service operations defined for the Npanf_ProseKey service are as follows: Register: It allows a consumer NF to store the Prose Context information; Retrieve: It provides to the NF service consumer of the CP-PRUK matching input criteria.
Title Path: Services offered by the 5G PAnF > Npanf_ProseKey Service > Service Operations > Register > General
Content: The Register service operation is invoked by a NF Service Consumer to request the PAnF to store the ProSe context information for a 5G ProSe Remote UE or to store the ProSe context information for a 5G ProSe End UE. The Register service operation is used during the following procedure: - PC5 security establishment for 5G ProSe UE-to-Network relay communication over Control Plane (see 3GPP TS 33.503 , clause 6.3.3.3.2) The NF Service Consumer (i.e. AUSF) shall request the PAnF to store the ProSe context information for a 5G ProSe Remote UE or to store the ProSe context information for a 5G ProSe End UE as shown in Figure 5.2.2.2.1-1 The NF service consumer (e.g. AUSF) sends a POST request to the resource representing the Prose Context Info for a 5G ProSe Remote UE or the Prose Context Info for a 5G ProSe End UE. On success, the PAnF responds with "204 No Content". If the user does not exist, HTTP status code "404 Not Found" shall be returned including additional error information in the response body (in the "ProblemDetails" element). On failure, the appropriate HTTP status code indicating the error shall be returned and appropriate additional error information should be returned in the POST response body.
Title Path: Services offered by the 5G PAnF > Npanf_ProseKey Service > Service Operations > Retrieve > General
Content: Figure 5.2.2.3.1-1 shows a scenario where the NF service consumer (e.g. AUSF) sends a request to the PAnF to retrieve the CP-PRUK. The request contains the CP-PRUK ID and Relay Service Code. The NF service consumer (e.g. AUSF) sends a POST request to the resource representing the Prose Key. On success, the PAnF responds with "200 OK" with the message body containing the ProseKeyResponse. If the user does not exist, or the ProSe Key does not exist in the in the PAnF, HTTP status code "404 Not Found" shall be returned and additional error information should be included in the response body (in the "ProblemDetails" element). On failure, the appropriate HTTP status code indicating the error shall be returned and appropriate additional error information should be returned in the POST response body.
Title Path: Services offered by the 5G PAnF > Npanf_ResolveRemoteUserId Service > Service Description
Content: This service enables an NF service consumer (i.e. SMF) to request the PAnF to resolve the Remote User ID. The following are the key functionalities of this NF service. - Resolve the Remote User ID
Title Path: Services offered by the 5G PAnF > Npanf_ResolveRemoteUserId Service > Service Operations > ResolveRemoteUserId > General
Content: The ResolveRemoteUserId service operation is invoked by a NF Service Consumer, i.e. SMF, towards the PAnF to Resolve the Remote User ID. The ResolveRemoteUserId service operation is used during the following procedure: - PC5 security establishment for 5G ProSe UE-to-Network relay communication over Control Plane (see 3GPP TS 33.503 , clause 6.3.3.3.2) The NF Service Consumer (i.e. SMF) shall resolve the Remote User ID by invoking the "get" custom method on the resource URI of "Resolve Remote User ID" resource, see clause 6.y.3.2.4. See also Figure 5.3.2.2.1-1. The NF service consumer sends a POST request to the resource representing the get custom operation. The request body shall contain the Remote User ID (CP-PRUK ID). On success, "200 OK" shall be returned. The response body shall contain the SUPI. If the user does not exist, HTTP status code "404 Not Found" shall be returned including additional error information in the response body (in the "ProblemDetails" element). On failure, the appropriate HTTP status code indicating the error shall be returned and appropriate additional error information should be returned in the POST response body.
