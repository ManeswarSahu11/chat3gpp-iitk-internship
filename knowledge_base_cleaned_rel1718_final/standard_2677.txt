Title Path: Introductory information > Introduction
Content: The integrity algorithm GIA4 computes a 32-bit MAC (Message Authentication Code) of a given input message using integrity key KI128. The approach adopted uses KASUMI in a form of CBC-MAC mode.

Title Path: Introductory information > Notation > Conventions
Content: The assignment operator "=", is used as in several programming languages. The following: variable = expression means that variable assumes the value that expression had before the assignment took place. For instance, x = x + y + 3 means (new value of x) becomes (old value of x) + (old value of y) + 3.

Title Path: Introductory information > List of variables
Content: [A, B]are 64-bit registers that are used within the function to hold intermediate values. an integer variable indicating the number of successive applications of KASUMI that need to be performed. [CONSTANT-F]a 32-bit parameter which is constant for any given FRAMETYPE input. a 1-bit input indicating the direction of transmission (uplink or downlink). an 8-bit input to the function indicating the type of frame to be protected. [INPUT-I]a 32-bit time variant input to the function. the 128-bit integrity key. a 128-bit constant that is used to modify a key. an input to the function which specifies the number of octets of message to be MAC’d (1-65536). the 32-bit message authentication code (MAC) produced by the function. the input octet stream of length M octets that is to be processed by the function. is the input padded string processed by the function.
